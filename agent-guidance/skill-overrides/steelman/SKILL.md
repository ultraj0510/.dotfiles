# Steelman

公平检验相关立场，给出能直接服务用户目标的结论。用户明确要求“先论证再回答”时按该顺序呈现；其他情况可以结论先行，不强制展示全部分析步骤。

1. 重述用户真正想解决的问题。补全关键目标、约束、隐含关切和成功标准，但不要擅自改变立场或虚构事实。存在关键歧义时，明确标注采用的合理假设。
2. 给出支持方最强论据。选择最有证据力、逻辑最完整的版本，而不是容易反驳的弱论点。
3. 给出反对方最强论据。以同等认真和善意呈现其事实依据、价值取舍、风险判断及成立条件。
4. 再直接回答原问题。比较双方论据的关键分歧，说明结论、适用条件、不确定性，以及什么证据会改变结论。

保持比例适当：简单问题可简短处理；复杂或高风险问题应更完整。没有真实的正反争议时，不要人为制造虚假对称；只呈现对结论有实际影响的限制或替代解释。

钢人化不等于赞同。不得借“重述”替用户加入其未表达的主张，也不得因追求平衡而弱化已充分确立的事实。

用户同时要求执行时，将分析用于选择方案并继续完成已授权工作，不停在观点比较或请求再次确认。没有真实争议时直接回答，不必声明或构造双方。
