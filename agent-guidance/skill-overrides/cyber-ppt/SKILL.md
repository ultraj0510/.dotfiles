# CyberPPT

目标是交付内容可信、结构清楚、视觉成熟且主要信息可编辑的 PPTX。默认自主推进到渲染验证和交付，不把故事线、风格或每页 QA 自动变成用户批准门。

## 工作方式

- 用户只要大纲、方案或风格探索时，仅完成该范围。用户要求完整 PPT 时完成整份交付，不止步于计划或样张。
- 默认依据材料、受众和已有模板选择故事线与视觉方向。只有缺失信息会实质改变交付目标且无法合理推断时才澄清；一般风格选择可自行决定并说明。
- 用户明确要求逐阶段或逐页确认时才设置相应检查点，已经批准的范围不重复确认。内部检查通过与用户批准分开记录，不能伪造 `user_confirmed=true`。
- 通用 `presentations` Skill 负责格式读写、工具和渲染能力；本 Skill 负责咨询内容与视觉质量。合并重复检查，不运行两套审批或交付流程。

## 默认生产流程

1. 读取相关源材料，提取支撑论点的数字、期间、单位、位置与限制。保留可追溯记录，不凭空补数据，也不把 ImageGen 文字作为事实来源。
2. 按受众目标构造论证与逐页计划。SCR 有帮助时使用；只有存在实质不同的故事线时才比较备选，不强制凑 2–3 套方案或 issue tree。
3. 使用用户模板或选择适合的视觉系统，统一画布、网格、文字层级、色板和图表语言。信息密度服务可读性，不强制每页塞满组件。封面和过渡页允许简洁。
4. 需要探索风格时选少量有区分度的样张。固定 8 张风格展示、每页 ImageGen 蓝图并非默认前置条件；用户要求时执行。生成图用于视觉资产或构图参考，图表和准确数据优先原生构建。
5. 先制作代表页检查布局，再完成其余页面；可安全批量生成。文字、数字、简单图表和表格保持可编辑。复杂视觉可以保留为图片并说明，不用整页截图代替可编辑交付。
6. 渲染并检查每页：截断、重叠、可读性、标签和图形避让、容器边界、表格密度、语言一致、图表语义和字体。修正后检查受影响页面，合并或导出改变版面时验证最终渲染。
7. 交付 PPTX、适用的预览和简短质量说明。保留源文件，遵循项目文件命名与版本规则，不强制创建多份版本号文件。

交付物语言优先遵循用户要求，其次材料主要语言，再参考对话语言。页级语言覆盖仅作用于指定页；执行元数据不得出现在页面可见文字中。

## 高保真与人工确认工作流

仅在用户明确要求 ImageGen 蓝图还原、逐页人工验收或旧版 CyberPPT 完整协议时，读取相关参考：

- [source-analysis.md](references/source-analysis.md)：详细证据表与素材池。
- [storyline.md](references/storyline.md)：详细 SCR 与页面结构。
- [visual-system.md](references/visual-system.md)：固定风格和逐页 ImageGen 蓝图。
- [ppt-production.md](references/ppt-production.md)：高保真重建、元素测量与单页制作。
- [quality-assurance.md](references/quality-assurance.md)：相应 manifest 和视觉门禁。

参考文件中的八风格、逐阶段停止、逐页用户确认、锁定注册表、SHA-256 和特定 strict 校验属于旧版完整协议，不自动适用于默认流程。本入口决定适用范围；仅借用其中一项技术方法不启用整套流程，也不因参考文字冲突停下来请用户裁决。

用户明确要求旧版完整协议时，先读取 [legacy-workflow.md](legacy-workflow.md)，保留其实际人工批准和验收要求。该文件保存原协议，只有在明确选择旧版时才加载。用户只要求高保真但授权自主完成时，使用可核验的内容、测量和渲染证据，不伪造人工确认字段。

`scripts/validate_pptx.py --manifest ... --visual-qa ... --strict` 的旧版高保真协议包含 `user_confirmed` 等人工确认检查，只用于匹配该协议的任务。默认自主流程使用通用 PPTX 结构、可编辑性和全页渲染检查，不用该旧协议宣称已通过自主流程。不要放宽校验器、伪造 manifest 或把真实视觉缺陷当成流程差异忽略。

## 失败与完成

工具不可用时先寻找能够满足同一交付要求的替代方法。用户明确指定的 ImageGen 或高保真要求无法满足时，说明具体限制，不偷偷换成低保真结果；其他独立工作仍继续。

完成依据是请求范围已实现、证据与编辑性检查完成、全页渲染已审阅，且影响交付的缺陷已处理。审美上仍可改进不自动阻塞交付；没有渲染能力或关键输入不足时，准确交付部分成果和未验证边界。
