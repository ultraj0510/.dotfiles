# 研究协作与候选裁决

在并行发现、重点候选独立估值及跨候选裁决时使用。普通单股追问只取需要的部分，不为每家公司启动完整研究组。

## 主 Agent 先定比较问题

从用户范围和现有记录确定两条线本轮要回答什么。指定核心池分工与扩展线索，建立简短的候选/任务表，复用当轮文档即可。委派包说明研究线、截止日、证券范围、待回答问题、原始输入位置、文件所有权和验收证据；只给必要上下文。

发现任务先输出线索与取舍，主 Agent 据此调整深评队列。额外调用优先用于：可能替换本线首选、关键估值分歧会反转排序、或可能揭示重大主张失败的候选；不按每家公司固定配额。缺少关键事实时先补事实，不能用更多 Agent 重复猜测。

用户选择重点深研时，按同一家公司的需求、供给与竞争、单位经济与资本、市场预期及反证拆问题；不按股票数量分摊后只交摘要。每项调查交付原始证据、支持或冲突、受影响假设及尚未解决的关键问题。主 Agent 判断哪些证据改变取舍，不以资料数量验收。广泛发现的并行要求只适用于已授权的发现范围。

## 三种任务职责

| 职责 | 交付 | 避免的无效工作 |
|---|---|---|
| 发现 | 新旧候选、发现入口、价格线索、最强替代、落选理由及实际覆盖 | 只维护熟悉名单或罗列行业新闻 |
| 独立估值 | 从原始事实独立选择关键假设与适合业务的模型，给现价隐含条件、估值区间与敏感性 | 只重算作者给出的目标价 |
| 挑战 | 能推翻主张或改变排序的具体证据、替代解释，以及检验后保留/修改判断的理由 | 为反对而反对或列通用风险 |

候选发现与初筛由主 Agent 显式指定 `gpt-5.6-sol` 执行，负责候选取舍、证据解释和进入深评队列的理由。脚本承担确定性转换与校验；`luna_worker` 承担资料抽取、整理、既定公式复算和测试。Sol 不可用时报告限制，由主 Agent 接管或确定替代，不静默降级为 Luna。独立估值、挑战与最终裁决按问题难度另行分配，不随初筛统一降级。

这是任务职责，不要求新增永久角色。可由不同实例的 `nikkei225_opportunity` 承担发现、估值或挑战；资料整理、计算和测试可交 `luna_worker`。作者不独立审阅自己；实际模型和可用角色如实记录，不自动启用 `luna-orchestrator`，不将研究判断强制交给小模型。

模型任务交接时附输入口径、假设来源、脚本和结果位置，以及哪些参数可改、哪些必须保持。Sol可承担阶段性证据解释与情景构造；长期经营路径、终值和重大分歧由主 Agent 按难度分配。Luna复算发现经济口径不明时交回判断者，不自行选择盈利持续期、估值倍数或概率。具体复算边界见 [双模型建模与复算](dual-model-method.md)。

## 独立形成，再交叉阅读

对值得额外投入的候选，共享可核实原始输入、价格时点、公司行动口径和分析问题；独立估值者在形成首版假设与计算前，不接收主作者目标价、评级或结论性摘要。记录各自首版后再交叉阅读。已看过结论则标明为知情复核，不称盲态独立形成。

独立工作不等于必须不同模型；相同模型和共同来源可能产生相同盲点，主 Agent 仍核对决定性原始证据。已有符合这些条件的独立工作可复用，不重复启动流程。发现新事实后，共享给相关研究者并更新比较基础，记录事实与假设变更，不假装两份使用不同输入的报告是同输入对照。

## 主 Agent 裁决，不拼接或投票

交叉比较先定位分歧：事实口径、经济假设、估值时点/方法、催化窗口，还是选择偏好。事实差异回到来源核对；假设差异用范围、敏感性及证据比较；需要补查时仅派发能改变结论的问题。不能用两份目标价平均或多数意见代替判断。

每条研究线分别回答：当前更倾向哪项主张，最强替代为何暂未胜出，价格或哪项关键假设变化会反转选择。期限不一致时先明确可比较窗口及方法，不能直接排序总涨幅。结论允许“不划算”或尚无可比较首选，资料缺口不能被强行排名掩盖。

在原有正文/审阅记录中留下：争议点、双方依据、补查或复算结果、采用/拒绝理由、剩余不确定性。复用现有报告，避免另建数据库或评分平台；同公司两条线共用事实附件但分别保留主张和排序。后续整合组合时检查共同驱动，不将多条主张当独立敞口。

## 调度与完成

独立读取和不同文件的工作按宿主容量并行；共享SBI界面与同文件写入串行，指定唯一整合者。发现完成再分配依赖其结果的估值任务，写者停止并交接后再接管。来源受阻只暂停依赖部分；无独立能力则说明未完成的复核，保留有依据的暂定判断，不冒称完整验收。

研究方法的强烈行动判断、数量建议及重大改判审阅要求继续适用，本页的重点候选投入不能替代它们。研究池扩展不授予账户操作、Paper/Live证券准入、发布或调度权限。

验收查看实际覆盖、可复算价格依据和被裁决的关键分歧；Agent数量、报告篇数和检查通过不证明研究质量提升。后续用真实前瞻记录检查新增线索是否影响选择、价格区间与反证如何被后续事实修正，保留旧版本，不以事后涨跌倒造发现成功。
