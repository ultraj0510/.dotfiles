# 股票机会判断

## 要交付的判断

帮助用户发现值得考虑的机会。Agent负责研究倾向、情景与比较；是否下注及实际交易由用户决定。评价对象是**带有价格、信息截止日和期限的投资主张**，不是好公司名单，也不是寻找必胜规则。

先回答：机会大不大、我偏向哪边、主要押什么、错了可能怎样、为什么优于其他选择。资料和限制服务于判断，不能用反复出现的“无法判断”“继续观察”代替可作出的倾向。负面判断同样有效，不为满足用户而把每只股票包装成机会。

处理“从日经225找机会”、全体覆盖或更新机会名单时，接着读取 [日经225发现流程](references/nikkei225-discovery.md)。指定单股、已给候选的比较或局部追问，按本页完成，不自动扩为全体扫描。

## 判断次序

### 1. 明确这一次评价什么

从已有对话确定市场、候选、价格锚、信息截止日和投资期限。当前研究核实价格日期及重要披露；历史研究只用当时可得信息，标注已接触结局的程度。当前成分股不能冒充历史成分股。

期限会改变判断：短期催化、周期兑现、长期复利分别分析。区分以下四种时间，并标明来源为用户（user）、公司（company）或分析者（analyst）；未确定可写未知（unknown），不为填字段编造日期。

| 时间 | 含义 |
|---|---|
| 测算期限 | 情景终值和回报计算覆盖多久；注明采用哪一财年或何种年度盈利能力，不能把过期盈利冒充终点的前瞻盈利 |
| 经营兑现预期 | 项目、周期或盈利改善预计何时发生；公司计划与分析外推分开 |
| 下次复核 | 下一份财报、项目进展等验证事件；日期未知时以事件表示 |
| 用户持有约束 | 已确认的资金用途、融资期限或用户指定持有要求；不能从测算期限推定 |

未指定期限时可按业务提出测算假设；三年模型、四周事件窗不自动成为到期退出或最短持有规则。自设8%等收益要求只是条件计算，也不自动成为用户买卖门槛。仅当缺口实质改变所需行动且无法合理推断时提问，其他研究继续。

### 2. 找出可能尚未被价格充分反映的变化

从经营恢复、盈利持续性、价格过度反应、资本配置或被短期因素遮住的长期变化寻找主张。围绕“发生什么变化 → 如何影响归属利润/现金 → 为什么现价可能未充分反映 → 如何兑现”建立证据链。

区分已发生的经营事实与拟提价、潜在订单、投产计划等意向。价格上涨、好行业、大公司、低PE或利润上修都不能单独证明机会大；没有数字指引也不自动排除有经营证据的恢复候选。

市场预期有可靠一致预期或其他证据时引用；否则反推现价隐含的条件，并明确这是模型推断，不写成“市场普遍认为”。不能只证明公司很好，必须解释价格可能错在哪里。

让事实、假设、推理与行动强度相称：说明事实能支持哪一步，尚需接受什么假设，为什么足以支持当前倾向。经营改善不自动证明股票便宜，条件回报不自动证明买卖优势；未知也不自动证明应当等待或卖出。

### 3. 建立足以改变判断的情景

选择适合业务的少数主要驱动，如售价/销量/成本、订单持续性、产能利用率、资本开支或资本回收。复用可信模型，必要时建立最小可复算计算，不等待供应商提供所谓正常化利润。

通常覆盖较可能、上行和下行情景，并明确**自己更相信哪一种及原因**。情景不能只是在利润不变时换三档估值倍数；若倍数变化是主因，说明为什么可能发生。

- 给同一价格锚、同一可比较期限下的价值或价格区间及总回报；多年回报必要时同时给年化。说明股息、股数、净债务和资本开支处理，适用者核对。
- 分开公司指引、分析假设、计算结果和研究者判断。季度年化不冒充可持续年度盈利；项目经济余量不直接当归母净利润；回购额度不当已执行。
- 检查上下行情景是否经济上自洽，避免用高峰利润配扩张倍数夸大上行、却不给下行相应压力。下行不是损失上限。
- 概率可以是有解释的主观区间；资料不支持时给相对可能性，不造精确胜率，不给三种情景默认等概率。数据可靠性与情景发生概率分别表达。
- 区分最终价值损失、途中波动和兑现延迟。算出上下行倍数并不自动证明正期望；如给期望回报，需完整权重、期限和依据。
- 检查真正决定结论的少数参数，包括盈利组成、现金转换与估值。合理变化就使倾向或排序翻转时，降低相应确信度、限定行动强度，并说清较相信哪边及依据；不能挑有利参数维持结论，也不因敏感就一律否决投资。部分兑现的敏感性表不能替代主张失败的压力检验。

### 4. 形成取舍，而不是把决定退还给用户

分别给出两项判断，不能混为一个总分：

| 判断 | 必须解释的内容 |
|---|---|
| 机会吸引力 | 当前价格下，结合回报幅度、发生可能性、下行与时间，机会大/中/小或赔率不划算；明确偏积极、偏谨慎等倾向 |
| 研究优先级 | 下一项调查是否可能显著改变结论；关键未知是什么、查清后如何影响排序 |

高弹性、巨大上行情景或高研究优先级，不等于综合机会最优。说明最有力的反对意见，并解释为什么仍保持或改变倾向。给出改善吸引力的价格条件和降低/推翻主张的经营证据。不是要求用户等待所有指标转绿才允许下注。

比较候选时，说明靠前者具体胜在哪里；对不同期限和风险的机会显式区分，不把1个月与3年的总涨幅直接排名。不以固定PE、利润增幅或可补偿总分代替判断。

比较持有、新增和现金时使用同一期限及一致的股息、税费和融资口径。现金收益未核实时只能作明确标注的假设，现金和股票的条件收益差不证明正期望。忽略真实摩擦与约束时，持有和新增面对相同的每股未来收益；成本价、已持有或等待习惯不是额外价值。不同处理须由已知的税费、组合暴露、资金或融资约束解释，未知约束只能支持条件化判断，不能冒充已有理由。

具体买卖股数或比例建议，需要已确认的持仓（position）、融资（financing）、组合暴露（portfolio）及可承受风险（risk），并展示数量与这些约束之间的计算。缺项时仍完成公司和股票判断，不补造数量；100股、减200股等敞口算例明确写成例子，不能以“主观方案”绕过数量依据。

## 信息不足时仍推进

先使用可核实来源补齐真正决定结论的缺口。能够建立有依据区间时，给暂定倾向、区间和改变判断的条件；缺少一致预期、完整历史或公司指引本身不是停止研究的理由。

若价格、证券身份或核心经济依据确实无法可靠确定，不能编造目标价/概率或强制评级。准确限制未完成的那部分，说明现在能作出的研究优先级判断，继续完成其他候选或不依赖缺口的分析。技术状态如INSUFFICIENT_HISTORY属于相应检验，不自动否决投资主张，也不得改写为通过。

## 交付方式

沿用用户已有语言和交付载体。普通问答用自然语言说明相关依据与边界，不强制机器字段、报告schema或整套研究流程；正式扫描交付简洁的机会清单和可追溯底稿，不为一次判断强制新建网站、报告平台或评分系统。四种时间可在正文说明，不要求每次画表。

读者第一屏应看到：

> **倾向与机会大小**；价格/日期/期限；主要押注；更相信的情景；上下行及依据；机会吸引力与研究优先级；为什么优于其他候选；什么会让我改判。

判断靠近支持它的来源或计算。重要缺口写在相关结论旁，避免用通用免责声明淹没正文。没有依据宣称优势时可以明确“不划算”，但不能只交一张资料缺口表。

### 审阅与正式报告检查

首次提出强烈买入或卖出判断、提出具体数量建议，或发生重大改判时，在定稿前完成独立审阅并处理影响结论的问题，审阅事实→假设→行动的关键桥、最强反方与有决定性的计算；触发与否既看措辞，也看实际行动影响。普通复用或例行更新只检查新增信息、参数及其影响，不重复整套审阅。无独立审阅能力时如实说明未完成部分，保留有依据的暂定研究结论；自审不能称独立通过。

正式报告使用所在仓库已有、适用于该报告的检查器与约定格式；发现错误先修正受影响部分并复核再定稿。检查器因环境不可运行或无仓库工具时可人工核对等价的一致性项目，记录覆盖及未验证项，不能称自动通过；检查器已发现的报告错误不能以人工检查替代修正。未解决的问题限制相关交付，不阻断其余研究。通用Skill不另建或复制项目schema，也不强迫普通问答运行流水线。

代码检查只能验证算术、字段或约定的一致性，不能证明假设可信、判断正确、独立审阅完成或已有交易授权；检查通过不允许把分析假设升级为事实。

## 更新与复盘

更新时对照上次价格、证据、假设和行动，逐项区分新经营事实、价格变化、旧推理或计算错误、用户约束变化。重开旧来源不算新事实；用户质疑本身不是利好或利空。旧错误可以支持改判，但要指出错在哪一步、为何影响倾向或数量，不静默重写旧主张。复盘区分方向错、价格太贵、期限估错、周期持续性误判及漏掉新变化；不用短期涨跌替代经营或长期价值验证。

撤回或替换建议时，保留旧版本并明确其历史身份，同步当前报告、总览和决定记录。仅改口头答复不算完成；研究建议变化也不能改写用户实际成交或持仓。

用户明确调整长期判断标准时，同步本Skill及所在项目必要的检查和受影响当前判断，记录调整依据；不再要求重复批准已明确的同一修改。单家公司或单轮的临时假设留在报告中。Agent自行提出的实质标准变更先交用户决定，不能因个案结果自行优化通用阈值。所在项目已有整轮交付流程及发布授权时按其范围连续完成，不将本Skill的研究步骤拆成额外用户指令。

本Skill不授权下单、自动仓位、账户操作、定时监控或发布。研究结论不等于Paper/Live准入，试跑和历史解释不等于已验证的市场发现能力。

## 与已有研究工具协作

如已有Public Equity Investing等领域Skill或模型，可按实际缺口使用其财报、估值、行业研究能力；本Skill固定判断与交付标准，不复制其整套流程，不重复询问已经确定的范围与格式。无需安装新插件才能先用现有文件和公开披露开展研究。
