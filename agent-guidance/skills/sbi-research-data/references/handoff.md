# 字段口径与既有数据层

## 已确认和仍未知的定义

依据[SBI官方数据定义](https://search.sbisec.co.jp/v2/popwin/info/trading/pop_domestic_screening_01.html)，2026-09-08核验；采用定义前检查来源是否更新。

|筛选器字段|定义与限制|
|---|---|
|PER(予)|最近股价 / EPS(予)；EPS具体期末未确认|
|EPS(予)|预期净利润 / 期中平均发行股数；财年、会计调整及拆股基准不能从列名补出|
|経常利益変化率(予)|（当前预测−过去预测）/过去预测绝对值×100；不是EPS修订率，跨财年是否同预测期未确认|
|目標株価乖離率(予)|（目标价−终值股价）/终值股价×100；正值表示目标较高，CSV当前价不一定是该终值基准|
|予想ブローカー数|来源覆盖人数；不等于每个预测指标的贡献人数|

“3个月前”是搜索日前3个月同日，休息日/不存在日期取前营业日，不是90交易日。最近股价每小时取得；页面更新时间、报告日期、预测源更新时间分别记录。变化率保持百分数单位，−1.5表示−1.5%，不变成−0.015。

LSEG详细报告另明示预期PER为未来4季度EPS口径，年度预测另列财年；不能将此定义套用到筛选器。报告中的当前、30日前、90日前预测也不能自动视为历史当时可得的完整PIT快照。

公司没有全年指引时保留事实：银行可能给净利目标，半导体公司可能只给半年/季度。不要自行年化或用NOP替换制造业营业利润。拆股同时检查公告日、生效日、来源每股值是否调整；未来拆股公告不代表当日已生效。

## 研究交接记录

沿用任务已有记录格式，无需为每次核对建新平台。字段至少能表达：

- 目标日期/代码集合及名单来源，观察时区、时间和时间依据；来源产品、入口、原文件位置和SHA-256。
- 证券代码保留字符串（含285A一类字母代码）；指标原名、原值、数值、单位、文件行或报告页。
- 预测期间、会计定义、股本/拆股基准、报告/公告日期；未确认项及理由。
- 筛选条件、比较日期/期间、返回集合；缺行与缺值区别、已验证的排除条件、未解决原因。
- 可比性结论与依据、允许用途、固定快照身份（如已导入）。

以上为研究语义，不是现有导入器的JSON schema；不能把额外字段直接塞进严格的v1采集契约。
