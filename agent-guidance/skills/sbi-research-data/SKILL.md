# SBI 研究取数

交付可追溯的来源观察，帮助研究者知道数据说了什么、尚未说明什么。用户指定的股票、日期、只读或试跑范围优先；不默认扩成225只研究。机会判断仍由 `equity-opportunity` 维护，本 Skill 不另建评分或以字段齐全作为股票入选标准。

## 选择入口

先复用任务中已有、足够新鲜且来源明确的本地材料。确需重新采集时，按问题选择入口；无需每次遍历所有页面。操作细节读 [SBI 界面取数](references/acquisition.md)，字段及存储交接读 [口径与数据交接](references/handoff.md)。

|需要|入口与来源|用途|
|---|---|---|
|目标名单、批量预期指标|SBI 国内株式 → 銘柄スクリーニング；Refinitiv|原生CSV；条件会排除证券，必须另留底表|
|明确期间的预测区间、人数与历史预测|个股「分析」→ LSEG/Refinitiv Stock Reports Plus详细报告|原生PDF；与筛选器分别确认口径|
|另一供应商的预测区间|个股「評価レポート」；ウエルスアドバイザー，分析师区块IFIS|报告日期的界面摘录，不能冒充原生CSV或最新预测|
|公司信息、四季报预测|HYPER SBI 2 企业信息/四季报；按页面署名|区分东洋经济预测和发行人正式指引|
|公司正式指引与拆股|发行人IR/TDnet原文|核对期间、会计口径及生效日期|

## 覆盖与缺失

- 全体筛选先保存仅含目标范围、未加财务条件的代码底表；同批记录来源、观察时间和条件。历史研究另核实目标日成分，当前SBI名单不是历史成分证据。
- 按研究所需字段取数。返回不足时移除条件或分组导出，逐代码比较集合；保留观察批次，不能只按总数宣称完整。分批顺序采集不能称原子同时点。
- 缺行、原值为空/横线、条件未通过、工具提取遗漏分别记录；未经逐条件或其他入口核实，不推断源数据不存在。
- 缺PER、负EPS或缺公司全年指引不删除目标名单中的公司。数据完整性与投资吸引力是不同问题，研究者可以继续使用适用的经营证据。
- 切换证券或筛选条件后等待正文代码、日期、最终数量更新一致；标题已更新不代表正文完成。辅助功能树未返回的表格先用截图核对。

## 可比性与交接

保留原文件和哈希，记录代码、指标、原值、单位、来源产品、报告/公告日期、观察时间、预测期间、会计及股本口径；未知明确为空并附原因。报告、CSV、公司指引分别保留，不拿较新的页面行情覆盖旧报告日期。

只有期间、指标定义及股本基准足以对齐时，才形成同口径差异。来源未说明的EPS财年、跨财年修订方式、拆股处理不能用数值相近来“验证”。条件算术须显式标为假设，不作为已确认预期差。

交付范围与已取得集合、各字段覆盖/缺失解释、证据位置/哈希、已确认定义、未决口径及适用用途。给机会研究Agent可用事实与需补证据，不从取数结果推导评级、买卖或Paper/Live准入。

## 操作边界

使用工具已支持的UI或正式接口。共享SBI界面串行操作；可并行分析已保存材料。保持正常登录会话，不保存/重放认证令牌或研究带认证参数的隐藏接口。登录过期时停止依赖登录的步骤，说明需用户完成登录，继续离线核验。

本 Skill 不授予账户操作、下单、监控调度、上传或发布权限。原始SBI报告/CSV保存在任务允许的本地数据目录，不放入Git或站点资源；不将取数任务变成无关账户信息采集。
